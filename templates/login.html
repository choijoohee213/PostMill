  1. Meta 개발자 대시보드 열기
  2. 이용 사례 → Threads API → 맞춤 설정
  3. 아래로 내려 사용자 토큰 생성기에서 쓰려는 계정의 토큰 생성
  4. 나온 값을 복사해 아래에 붙여넣기
